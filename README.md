# HDBoard – Tải về

Bảng dạy học miễn phí của **Hoàng Dũng Edu**: cầm bút viết luôn, vẽ tay tam giác hay đường tròn là ra hình chuẩn.

- **Tải bản Windows 1.0:** [HDBoard.exe](https://github.com/derekdaydoi/hdboard-download/raw/main/HDBoard.exe) (khoảng 4 MB, Windows 10/11, chạy offline)
- Trang giới thiệu: https://hoangdungedu.io.vn/tool/hdboard/

Chạy file, chọn **Yes** để cài vào máy (tạo lối tắt) hoặc **No** để chạy luôn.
File chưa ký số nên Windows SmartScreen có thể cảnh báo: chọn **More info → Run anyway**.

Kho này chỉ chứa file cài đặt.
